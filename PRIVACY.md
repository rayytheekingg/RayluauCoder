# RayluauCoder privacy policy

Last updated: 2026-11-05

RayluauCoder doesn't collect, store, or send personal data, conversations, or your code. It has no account, analytics, telemetry, or server of its own.

## What it downloads

The plugin's scripts make plain download requests for public reference files. These requests send no project data, but the hosts receive normal request details, such as your IP address, under their own privacy policies.

| File | Host | Purpose |
| --- | --- | --- |
| Roblox API dump | `setup.rbxcdn.com`, using the current version from `clientsettings.roblox.com` | Verifying Roblox APIs |
| Roblox type definitions | `raw.githubusercontent.com` | Type checking |
| Roblox documentation source | `github.com`, only if you run `maintain` | Checking the plugin against the docs |

## What it stores

Those files are cached on your computer, in `%LOCALAPPDATA%\rayluaucoder` or `~/.cache/rayluaucoder`, until you delete them. To remove them, delete that folder.

## Tools you connect

If you connect Roblox Studio or install optional tools, those tools are covered by their own terms and privacy policies. Your conversations with Claude are covered by Anthropic's.
